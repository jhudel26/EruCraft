# EruCraft - Premium Resume Builder

EruCraft is a modern, high-performance resume generator designed to help professionals craft stunning resumes in minutes. Built with vanilla JavaScript and CSS, it offers a seamless real-time editing experience with multiple professional templates.

## ✨ Features

- **Real-time Preview**: See your changes instantly as you type.
- **Multiple Templates**: Choose from 10+ professional layouts, including Modern, Minimalist, Creative, and ATS-friendly designs.
- **Auto-Save**: Never lose your progress. Your data is automatically saved to local storage.
- **Customization**: Personalize colors, fonts, and spacing to match your professional brand.
- **Export Options**: Download your resume as a professional PDF or export/import your data as JSON.
- **Dark Mode Support**: Comfortable editing in any lighting condition.
- **Privacy First**: All your data stays on your device. No server-side storage.

## 🚀 Getting Started

1. Clone the repository or download the source code.
2. Open `index.html` in any modern web browser.
3. Start crafting your professional resume!

## 🛠️ Built With

- **HTML5/CSS3**: Modern layout and styling.
- **Vanilla JavaScript**: High-performance, dependency-free core logic.
- **Lucide Icons**: Beautiful, consistent iconography.
- **Google Fonts**: Premium typography for a professional look.
